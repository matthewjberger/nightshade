Reflect on the work done in this session by reading the code. Do not run anything.

1. Read every file that was written or changed
2. Ask yourself:
   - Does the implementation match what was asked for?
   - Are there bugs, logic errors, or missed edge cases?
   - Is the architecture clean, or did shortcuts creep in?
   - Is there dead code, unnecessary complexity, or inconsistency?
   - What would break if someone extended this?
   - What would you do differently if starting over?
3. Report what's solid and what needs another pass

The goal is to catch problems before moving on, not to rubber-stamp the work.
