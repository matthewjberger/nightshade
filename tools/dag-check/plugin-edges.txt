# The plugin-feature edges that are allowed, one per line as
# "consumer -> dependency". A composition root takes another plugin whole,
# with features = ["plugin"], so it can register that plugin's systems and
# reach its behavior. The window composes the platform and the scene, the
# interface reaches platform and scene behavior, graphics propagates transforms
# through the scene, and prefab spawns through the scene and graphics.
#
# A call to add_plugin on another crate's plugin counts the same way, because
# composing a plugin drives that capability whether or not a feature edge says
# so. nightshade-openxr stands in for the window and composes the wgpu backend
# itself, which is the one place a second composition root exists.
#
# Every other crate must take only the contract of what it names, with
# default-features = false and features = ["contract"], so naming a type never
# links the other capability. An edge that is not listed here fails the check.
#
# Keep this list short. A new entry means one more crate now links another
# plugin's behavior, which is the thing the check exists to make deliberate.
