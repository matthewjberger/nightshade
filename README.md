# Nightshade 

`Nightshade` is a data-oriented game engine written in rust 🦀

## Quickstart

### Desktop

```bash
cargo run -r -p editor
```

### Justfile

If you have [just](https://github.com/casey/just) installed:

```bash
just run
```

> Run `just` with no arguments to list all commands
